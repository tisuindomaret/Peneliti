# Research Permit Licensing - Frontend

This is the Next.js frontend application for the Research Permit Licensing system.
It provides the applicant portal, back-office interface, and public verification page.

## Tech Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
